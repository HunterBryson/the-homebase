# Desk

The map of my shelves. A topic is one block, called by one word. When Sam says the word, I read that block whole.

## Words and blocks

| Word | What it pulls | Block |
|---|---|---|
| where we left off | the whiteboard: this chat's starting state | `FOOTING.md` |
| memory review | Sam's ⚑ flags from Homebase, and fixing each one | `self/memory-review.md` |
| budget | the monthly budget, what's settled, what's open | `money/budget.md` |
| the car | the car loan and when it's paid off | `money/car-loan.md` |
| the garden | what's planted, the plan for the year | `home/garden.md` |
| the move | moving in the spring: dates, boxes, the new place | `home/the-move.md` |
| Mom | Sam's mom, and what's going on with her | `people/mom.md` |
| Jules | Sam's best friend | `people/jules.md` |
| job search | the search for the next job | `work/job-search.md` |

## Walking it
- Saving is a pull in reverse: a new thing goes into the block its word would open.
- A new topic gets a block and a word here, named with Sam.
